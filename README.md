# REVÉLAT — Waitlist

Pre-launch marketing + email-capture landing page for **REVÉLAT**, the live
fashion-auction app. Built with Next.js (App Router) + Tailwind, brand-matched
to the product, with first-class SEO and AI-crawler discovery.

## Stack

- **Next.js 15** (App Router, React 19, TypeScript)
- **Tailwind CSS 3** — brand tokens mirror the app (`app/lib/tokens.ts`)
- **next/font** — Playfair Display (display) + Inter (body), self-hosted at build
- Dynamic OG card via `next/og` (no static asset to maintain)

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # production build
```

## Waitlist storage

The signup API (`app/api/waitlist/route.ts`) validates the email and hands it to
a pluggable sink (`lib/waitlist.ts`) that auto-selects a destination by env var:

| Set this | Result |
|---|---|
| `RESEND_API_KEY` + `RESEND_AUDIENCE_ID` | adds the contact to a Resend audience |
| `WAITLIST_WEBHOOK_URL` | POSTs the entry to your webhook (Zapier/n8n/custom) |
| _(nothing)_ | signup succeeds in the UI but is **not persisted** (dev only — logged with a warning) |

Copy `.env.example` → `.env.local` and set one before going live. See `.env.example`.

## SEO / crawlers

- **`/robots.txt`** — generated by `app/robots.ts` (allows all, disallows `/api`, points to the sitemap).
- **`/sitemap.xml`** — generated by `app/sitemap.ts`.
- **`/llms.txt`** — `public/llms.txt`, the [llmstxt.org](https://llmstxt.org) standard describing the product for LLMs/AI crawlers.
- **JSON-LD** — `Organization` + `WebSite` structured data in `app/layout.tsx`.
- **OpenGraph / Twitter** — full metadata + dynamic social card (`app/opengraph-image.tsx`).
- Set `NEXT_PUBLIC_SITE_URL` so canonical URLs, robots, and sitemap use the real origin.

## Deploy

Zero-config on **Vercel**: import the repo, set `NEXT_PUBLIC_SITE_URL` and a
waitlist-sink env var, deploy. Any Node host works (`npm run build && npm start`).
